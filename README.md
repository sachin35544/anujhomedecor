## Overview

Anuj Home Decor is a visually rich, responsive business landing page created to showcase a home interior and decor brand. The website is designed to highlight premium interior products and services, with elegant layouts, warm color themes, and gallery-driven storytelling.

The project is built as a lightweight static website with a modern aesthetic and mobile-friendly layout, making it ideal for a local decor business, interior studio, or home enhancement brand.

## What this project includes

- Custom wallpaper design and installation solutions
- Roller blinds for privacy and modern styling
- 3D and 5D decorative wall panels
- Exterior decor and design enhancement ideas
- Product showcase gallery with premium visual presentation
- Contact details and social media links for customer engagement

## Key Features

- Elegant hero banner with strong brand messaging
- Responsive layout for desktop, tablet, and mobile devices
- Service cards for core offerings
- Feature sections highlighting design benefits
- Gallery section for completed work and design inspiration
- Social links and contact information integrated into the footer
- Clean, minimal JavaScript for smooth interactions

## Tech Stack

- HTML5 for page structure
- CSS3 for layout, styling, responsiveness, and visual design
- JavaScript for lightweight interactivity
- Google Fonts and Remix Icons for modern typography and icons

## Design Style

The visual language of the website uses:

- Warm earth tones like beige, brown, cream, and muted terracotta
- Soft card layouts with rounded corners and shadow depth
- Spacious typography and elegant headings
- Luxury interior storytelling through imagery and composition
- Clean white and neutral section backgrounds for premium contrast

## How to Run

Since it is a static website, you can open it directly in a browser:

```bash
# Option 1: Open directly
open index.html

# Option 2: Run a local server
python -m http.server 8000
```

Then visit:

```text
http://localhost:8000
```
